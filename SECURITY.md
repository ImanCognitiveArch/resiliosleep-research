# Security and privacy reporting

Please do not open a public issue containing participant data, questionnaire exports, screenshots with personal information, credentials, signing material, or exploit details that could endanger active users.

For a suspected vulnerability:

1. describe the affected version and device/Android version;
2. provide minimal reproduction steps without participant data;
3. state the potential privacy or integrity impact;
4. wait for a private acknowledgement before public disclosure.

The public showcase does not distribute production source, signing secrets, or participant-level records. Academic access to controlled materials is reviewed case by case.
